# Homework 2: Drum Kit Engine

## Objective
Build an interactive drum kit using HTML, CSS,
and Vanilla JavaScript.

## M1: HTML Data Contract
- [ ] Create semantic HTML structure.
- [ ] Create drum pads with data-key attributes.
- [ ] Define audio paths using data-sound.
- [ ] Commit HTML contract before JavaScript.

## M2: Polyphonic Audio Engine
- [ ] Implement independent sound playback.
- [ ] Allow multiple sounds to overlap.
- [ ] Test sound playback.

## M3: Keyboard Event Handling
- [ ] Implement keydown listener.
- [ ] Use event.key.
- [ ] Prevent repeated events using event.repeat.
- [ ] Test all keyboard bindings.

## M4: FIFO Beat Recorder
- [ ] Record key and timestamp for each beat.
- [ ] Store beats in chronological order.
- [ ] Implement replay and clear.
- [ ] Test recorded beat sequences.
